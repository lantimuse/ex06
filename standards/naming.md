# Marlow Wharf — Family Naming

    <CATEGORY>_<Descriptor>_<Variant>

| Prefix | Category |
|---|---|
| `DR_` | Doors |
| `WN_` | Windows |
| `CW_` | Curtain wall panels |
| `RL_` | Railings |
| `GN_` | Generic model |

Descriptor is what it is. Variant is geometry. Sizes are types, four digits,
width before height.
