# Marlow Wharf — Parameter Standard

| Parameter | Datatype | Instance/Type | Drives |
|---|---|---|---|
| `MW_Leaf_Width` | Length | Type | Panel width |
| `MW_Leaf_Height` | Length | Type | Panel height |
| `MW_Frame_Depth` | Length | Type | Frame extrusion |
| `MW_Fire_Rating` | Text | Type | Schedule only |
| `MW_Hardware_Set` | Text | Instance | Schedule filter |

Geometry is type. Placement is instance. Anything scheduled is shared.
