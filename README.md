# Marlow Wharf — Family Standards

Naming, parameter and QA standards for the Marlow Wharf loadable family
library, plus the small scripts that check content against them.

## What is in here

- `standards/` — the rules families must obey
- `docs/` — how to apply them, and why they are what they are
- `scripts/` — checks that can be run against an exported schedule

## What is not in here

Model and family files. They live on the project server; this repository holds
the text that governs them.
